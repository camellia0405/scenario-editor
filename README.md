# SCENARIO_EDITOR - 本文取り込みエディタ

見本画像のような「本文から取り込み」ボタンを備え、PDF / TXT ファイルの文字を読み込んでリッチテキスト編集できるブラウザツールです。

## フォルダ構成

```
SCENARIO_EDITOR/
├── css/
│   └── style.css
├── js/
│   └── app.js
├── index.html
└── README.md
```

## 特徴

- **PDF・TXT対応**: 左上の「本文から取り込み」ボタンからファイルを選択
- **リッチテキスト編集**: 太字 / 斜体 / 下線 / 取り消し線 / 文字色 / 背景色 / 見出し / リスト / 引用 / **コードブロック** など
- **コードブロックの色カスタマイズ**: 右パネルで背景色・文字色を自由に変更可能
- **完全ローカル動作**: データは `localStorage` のみに保存。サーバーへの送信は一切なし
- **PC・iPad対応**: レスポンシブデザイン + タッチ操作対応
- **目次自動生成**: 見出し (H1〜H3) から左側に目次を生成し、クリックでジャンプ
- **TODOリスト・概要メモ**: 右パネルでシナリオ作成をサポート
- **エクスポート**: HTML / プレーンテキストとしてダウンロード可能
- **自動保存**: 30秒ごとの自動保存（設定でON/OFF）

## 使い方

1. このフォルダをVSCodeで開く
2. `index.html` をブラウザで直接開くか、簡易サーバーを起動する

### 簡易サーバー例（推奨）

```bash
# このディレクトリで
python3 -m http.server 8765
# ブラウザで http://localhost:8765 を開く
```

または VSCode の Live Server 拡張機能を使うと便利です。

### 操作

| 操作 | 説明 |
|------|------|
| 本文から取り込み | PDF または TXT を選択して本文に挿入 |
| ツールバー | 選択範囲に書式を適用 |
| Ctrl/Cmd + S | 手動保存 |
| 右パネルの色ピッカー | コードブロックの見た目を変更 |
| 目次クリック | 該当見出しへスムーズスクロール |

## 技術構成

- **HTML / CSS / Vanilla JS** （ビルド不要）
- **Quill.js 1.3.7** : リッチテキストエディタ
- **PDF.js 2.16.105** : クライアントサイドPDFテキスト抽出
- **localStorage** : 永続化

## 注意点・制限事項

1. **PDFのテキスト抽出精度**  
   - テキストベースのPDFは良好に抽出されます。  
   - スキャン画像のみのPDF（画像PDF）は文字が抽出できません。OCRが必要な場合は別途対応が必要です。  
   - 複雑なレイアウト（段組み・表）では改行位置が崩れることがあります。

2. **文字コード**  
   - TXTはUTF-8を前提としています。Shift_JISなどの場合はブラウザ側で文字化けする可能性があります。

3. **プライバシー**  
   - ファイル内容は一切外部に送信されません。すべてブラウザ内で処理されます。  
   - CDNからQuillとPDF.jsを読み込むため、初回はインターネット接続が必要です（その後はキャッシュでオフラインでも動作する場合があります）。

4. **ストレージ容量**  
   - localStorageの上限（通常5〜10MB程度）を超えると保存に失敗します。大きな文書は「HTML/TXTエクスポート」でバックアップしてください。

## カスタマイズのヒント

- `styles.css` の `:root` 変数で色や幅を変更可能
- `app.js` の `toolbarOptions` でツールバー項目を追加・削除可能
- Quillのテーマやモジュールを変更してさらに高機能化できます

## 開発環境

- VSCode のみで完結
- 追加のNode.jsビルドやパッケージインストールは不要（CDN利用）
